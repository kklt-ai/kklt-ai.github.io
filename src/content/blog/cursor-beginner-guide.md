## 为什么是 Cursor？

传统写代码的流程是：想清楚 → 查文档 → 敲代码 → 调试。而用 Cursor，你只需要把「想清楚」这一步做好，剩下的交给 AI。

它的核心能力有三个：

1. **Tab 补全**：比普通补全聪明得多，能预测你接下来的整段改动
2. **Chat 对话**：直接在编辑器里问问题，AI 能看到你的代码上下文
3. **Agent 模式**：给它一个任务，它自己创建文件、改代码、跑命令

## 安装与配置

去官网下载安装包，登录账号即可。推荐的初始设置：

```json
{
  "editor.fontSize": 14,
  "editor.formatOnSave": true
}
```

## 第一个练手项目

试着对 Agent 说：

> 帮我做一个待办清单网页，能添加、勾选、删除任务，数据存在 localStorage 里。

看着它几分钟内把项目搭好，你就会明白什么叫 vibe-coding 了。

## 小结

- 把需求描述清楚，比会写代码更重要
- 遇到报错直接把错误信息贴给 AI
- 多用 Agent 模式做完整任务，少自己抠细节
