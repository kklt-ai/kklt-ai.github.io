# 导入 B 站视频到视频栏目

把用户给的 B 站视频链接导入本博客的 `/videos/` 栏目和首页「视频教程」区块。

## 步骤

1. **提取 BV 号**：从用户输入中找出所有 `BV[a-zA-Z0-9]+` 模式的 BV 号。用户的消息常带有标题、【】、share_source 等分享参数，忽略这些噪音，只取 BV 号；纯 BV 号也可以直接接受。

2. **运行抓取脚本**（可一次传多个）：

   ```bash
   node scripts/fetch-bilibili-videos.mjs <BV号1> <BV号2> ...
   ```

   脚本会抓取标题/简介/封面/发布日期，封面保存为 `public/covers/bili-<BV号>.jpg`，并按日期倒序回写 `src/data/videos.ts`（已有视频会一并刷新）。

3. **检查抓取结果**：
   - 用 `git diff src/data/videos.ts` 检查新增条目：标题、日期是否正确，简介是否被合理截断。
   - 确认 `public/covers/` 下对应的 `bili-<BV号>.jpg` 已生成；抽查新封面用 Read 工具看一眼，确认是正确的视频封面而不是占位图。
   - 如果标题/简介需要润色（比如简介截断位置不当），直接编辑 `src/data/videos.ts` 中对应条目，不要重跑脚本（会覆盖手动修改）。

4. **验证构建**：

   ```bash
   npm run build
   ```

   确认构建成功且没有新增警告。

5. **汇报结果**：列出本次导入的视频（日期 + 标题），说明 `/videos/` 页面和首页「视频教程」区块（最新 3 个）会自动包含它们。

## 注意

- 脚本失败常见原因是 B 站接口限流或链接无效，把脚本报错原样告诉用户，不要猜测重试太多次。
- 不要改动视频页、首页或脚本本身的代码，除非用户另外要求。
